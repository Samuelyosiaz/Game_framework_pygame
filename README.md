# Overview

I writed this code to practice my skills in python, using libraries like pygame and to get an approach to game framework experimenting platforms like unity or nreak engine. For this time, I used a more familiar way to develop a game like this library.

This game uses pygame to create blocks as an object with properties, as well as a ball that interacts with the block, bousing on them and on the limits of the screen, and specially, an small and horizontal platform that moves to left or right with the keys of the keyboard. We need to avoid the ball falling in the button of the screen and make it bounce with every block to desapear all of them.

[Software Demo Video](https://youtu.be/JMeRPB0wdy0)

# Development Environment

I used only plain python and pip to compile the code. I used some libraries like arcade that is the principal one that lets the game be displayed and to create the interactive blocks as well as methods to handle interactions between the objects. Also math and random that lets the blocks be displayed in random ways and to handle their movements.
